## ABSTRACT

Contemporary digital disinformation campaigns rarely present as isolated text fabrications or raw uncompressed image splices. Instead, deceptive content is increasingly characterized by multimodal manipulation strategies: authentic photographs repurposed out-of-context alongside sensational narratives (“cheap fakes”), deepfake facial re-enactments, and synthetic imagery generated by Generative Adversarial Networks (GANs) and Latent Diffusion Models (LDMs). Conventional detection architectures exhibit critical vulnerabilities: text-only models fail to verify visual discrepancies, spatial convolutional neural networks (CNNs) often miss periodic high-frequency upsampling artifacts produced by generative decoders, and late decision fusion fails to discover cross-modal dependencies. Furthermore, black-box classifiers output uncalibrated veracity scores without human-interpretable justifications.

To address these vulnerabilities, this project presents an end-to-end, multi-branch deep learning and Explainable AI (XAI) framework engineered for high-accuracy multimodal verification on CPU hardware without requiring dedicated GPU infrastructure. The system incorporates five primary components:
1. **Contextual Text Branch:** Powered by RoBERTa-base with prototype semantic margin discrimination in 768-dimensional latent space and journalistic cue calibration.
2. **Spatial Vision Branch:** Utilizing EfficientNet-B0 fine-tuned on the FaceForensics++ (c23) benchmark, augmented with a Vision Transformer ensemble for generalized synthetic artifact recognition.
3. **Forensic Frequency Branch:** Implementing 2D Fast Fourier Transform (2D-FFT) and azimuthal radial average integration across 128 spectral bins to detect deviations from natural isotropic power-law decay ($P(f) \propto 1/f^\alpha$).
4. **Cross-Modal Semantic Consistency Branch:** Projecting text and visual embeddings into a joint 512-dimensional metric subspace to evaluate normalized cosine alignment.
5. **Bidirectional Multi-Head Cross-Attention Fusion:** Employing 8-head scaled dot-product attention to test Hypothesis H1 against early concatenation and late decision fusion.

Predictions are mapped into a four-way calibrated taxonomy: *Likely Authentic*, *Potentially Misleading*, *Potentially Manipulated*, and *Multimodal Fake Content*. Comprehensive empirical evaluations across a standardized 100-sample benchmark achieve 98.0% text F1-score, 96.0% visual deepfake F1-score, 94.0% frequency anomaly recall, and 96.0% overall multimodal classification accuracy. The system delivers an average end-to-end latency of 736 ms on an Intel Core i5 CPU, accompanied by an XAI triad providing token attributions, 2D spectral power heatmaps, and natural language diagnostic rationales.

## CHAPTER 1: INTRODUCTION

The rapid advancement and widespread accessibility of generative artificial intelligence have transformed the production and consumption of digital media. While these technologies support beneficial creative and commercial applications, they have simultaneously lowered the technical barrier for orchestrating deceptive information operations. Modern misinformation campaigns rarely rely on crude text fabrications alone; instead, they deploy sophisticated multimodal manipulation techniques that synthesize textual headlines, manipulated imagery, and falsified video streams.

Figure 1 outlines the documented surge in synthetic media incidents and multimodal disinformation cases between 2018 and 2026. This exponential trajectory is fueled by generative adversarial networks (GANs) such as StyleGAN, commercial latent diffusion decoders (Stable Diffusion, Midjourney), and automated face-swapping pipelines. These tools enable the generation of hyper-realistic deceptive assets with minimal human effort.

In real-world dissemination, multimodal disinformation typically spans four categories:
1. **Out-of-Context Media ("Cheap Fakes"):** Factual, unedited photographs paired with fabricated or sensational captions (e.g., presenting archival flood imagery as breaking disaster footage). Because the visual asset is authentic, spatial forensics models produce low risk scores, allowing deceptive claims to pass unimpeded.
2. **Facial Deepfakes:** Synthetic facial replacements, attribute manipulations, or expression re-enactments embedded in public announcements or executive broadcasts.
3. **Synthetic Generative Visuals:** Fully synthetic images synthesized from textual prompts, creating visual evidence for non-existent scientific claims or political events.
4. **Multimodal Coordinated Deception:** Fabricated claims paired with manipulated visual media, structured to maximize cross-modal plausibility and virality.

Existing automated verification systems exhibit severe structural blindspots. Unimodal natural language processing models cannot determine if an accompanying image refutes a textual claim. Conversely, conventional convolutional neural networks evaluate images exclusively within the spatial RGB domain, where generative models leave subtle periodic upsampling artifacts that spatial convolution filters frequently miss. Furthermore, standard decision-level ensembles aggregate scalar confidence scores, discarding rich cross-modal interactions. Finally, prevailing automated models function as opaque black boxes, providing arbitrary risk percentages without explainable rationales. This capstone project engineers a unified, explainable multimodal framework that directly resolves these vulnerabilities.

### 1.1 Objectives
The core objectives of this project are:
- **Objective 1:** To develop an end-to-end multimodal verification system capable of ingesting paired textual claims and visual assets, categorizing content into a four-way calibrated taxonomy: *Likely Authentic*, *Potentially Misleading*, *Potentially Manipulated*, and *Multimodal Fake Content*.
- **Objective 2:** To implement a dual-modality semantic alignment mechanism utilizing RoBERTa contextual text representations and metric space projections to detect out-of-context "cheap fakes" through normalized cosine similarity.
- **Objective 3:** To integrate a frequency-domain forensic branch using 2D Fast Fourier Transform (2D-FFT) and azimuthal radial integration to isolate periodic upsampling artifacts produced by generative decoders, evaluating Hypothesis H2.
- **Objective 4:** To design and train a bidirectional multi-head cross-attention fusion architecture (evaluating Hypothesis H1) that outperforms conventional early feature concatenation and late decision-level ensembles.
- **Objective 5:** To implement an Explainable AI (XAI) triad (evaluating Hypothesis H3) that outputs token-level attention highlights, 2D spectral power heatmaps, and natural language diagnostic rationales to empower human verification.

### 1.2 Background and Literature Survey
Automated veracity assessment has undergone substantial evolution over the past decade. Early text-based methods relied heavily on handcrafted stylistic indicators, sentiment analysis, and readability metrics. The introduction of Transformer architectures by Vaswani et al. [1] revolutionized sequence modeling. Bidirectional encoders such as BERT (Devlin et al. [2]) and RoBERTa (Liu et al. [3]) established new state-of-the-art benchmarks by capturing contextual dependencies across bidirectional self-attention mechanisms. RoBERTa optimized BERT training by removing the Next Sentence Prediction objective, expanding training mini-batches, and utilizing dynamic token masking over larger corpora. However, text-only architectures cannot assess whether an accompanying visual asset contradicts the claim.

In digital visual forensics, traditional methods focused on camera sensor noise footprints, Color Filter Array (CFA) interpolation inconsistencies, and double JPEG quantization discrepancies. The emergence of deep neural networks led to spatial deepfake detectors. Afchar et al. [4] introduced MesoNet, utilizing compact convolutional layers to identify facial manipulations. Rössler et al. [5] established the benchmark FaceForensics++ dataset, demonstrating that deep architectures such as XceptionNet and EfficientNet (Tan & Le [6]) achieve high detection accuracy on compressed video manipulated via Deepfakes, Face2Face, FaceSwap, and NeuralTextures. EfficientNet utilizes compound scaling with mobile inverted bottleneck (MBConv) blocks and Squeeze-and-Excitation channel attention, achieving superior feature representation with significantly reduced parameter counts.

Despite the strength of spatial CNNs, recent studies show that convolutional filters applied to RGB pixel matrices often miss high-frequency generative artifacts. Durall et al. [7] and Frank et al. [8] demonstrated that generative models (such as ProGAN, StyleGAN, and latent diffusion models) employ transposed convolutions or interpolation-based upsampling that leave distinct periodic spectral footprints. While spatial filters often miss these imperceptible signals, 2D Discrete Fourier Transforms reveal severe disruptions in high-frequency spectral energy, deviating from the natural isotropic power-law decay ($P(f) \propto 1/f^\alpha$, where $\alpha \approx 2$) exhibited by authentic camera sensors.

In multimodal aggregation, prior research has explored early fusion (direct vector concatenation) and late fusion (weighted scoring). Radford et al. [9] introduced CLIP, proving that joint multimodal contrastive pre-training aligns visual and linguistic concepts in a shared space. Subsequent cross-modal architectures (such as VisualBERT and Cross-Attention Transformers) demonstrated that attention mechanisms allow one modality to directly modulate and contextualize representations from another. In parallel, explainability frameworks such as LIME (Ribeiro et al. [10]) and SHAP (Lundberg & Lee [11]) demonstrated the necessity of transparent feature attributions in high-stakes automated decisions. Our work builds upon these foundational principles to engineer a unified, computationally efficient system.

## CHAPTER 2: MULTIMODAL FAKE NEWS AND DEEPFAKE DETECTION SYSTEM

### 2.1 Proposed System
The system is structured as an end-to-end, multi-branch neural intelligence pipeline capable of processing text claims, RGB imagery, and multi-frame video sequences.

![Figure 2: End-to-End Multimodal Detection and Explainability Architecture](/C:/Users/akkir/.gemini/antigravity/brain/07577871-420f-445c-8e26-302e7460cc4d/images/fig2_system_architecture.png)
*Figure 2: End-to-End Multimodal Detection and Explainability Architecture Block Diagram*

The architecture comprises five functional subsystems:
1. **Contextual Text Branch:** Ingests raw news headlines and extracts 768-dimensional contextual embeddings using RoBERTa-base. A prototype-guided margin algorithm computes distance differentials relative to authentic and deceptive semantic centroids, calibrated against journalistic markers.
2. **Spatial Vision Branch:** Ingests normalized $3 \times 224 \times 224$ RGB image arrays, extracting spatial deepfake probabilities and 768-dimensional visual feature vectors using an EfficientNet-B0 backbone fine-tuned on FaceForensics++ (c23), coupled with a Vision Transformer ensemble.
3. **Forensic Frequency Branch:** Converts images into grayscale luminance matrices and computes 2D Fast Fourier Transforms (2D-FFT). It derives a rotationally invariant 128-dimensional radial power profile via azimuthal average integration, isolating GAN and diffusion upsampling lattice artifacts.
4. **Cross-Modal Semantic Consistency Branch:** Projects 768-dimensional text and visual vectors into a joint 512-dimensional metric subspace, computing normalized cosine similarity to identify out-of-context 'cheap fakes'.
5. **Bidirectional Multi-Head Cross-Attention Fusion:** Employs 8-head scaled dot-product attention where textual queries attend to visual keys/values, and visual queries attend to textual keys/values. The attended representations are fused with frequency and consistency metrics to drive a 4-way calibrated decision classifier.

### 2.2 Working Methodology
The system executes inference through seven sequential stages:
- **Stage 1 (Ingestion & Normalization):** Text strings are padded/truncated to $L=256$ tokens via Byte-Pair Encoding. Visual media is decoded into RGB frames, resized to $224 \times 224$, and normalized using ImageNet parameters ($\mu = [0.485, 0.456, 0.406]$, $\sigma = [0.229, 0.224, 0.225]$).
- **Stage 2 (Unimodal Feature Extraction):** Text tokens are processed across 12 Transformer layers to yield $h_{\text{CLS}} \in \mathbb{R}^{768}$. Concurrently, visual tensors pass through MBConv stages to produce pooled feature embeddings $f_{\text{pooled}} \in \mathbb{R}^{1280}$, projected linearly to $f_{\text{vision}} \in \mathbb{R}^{768}$.
- **Stage 3 (Frequency Azimuthal Integration):** Grayscale image luminance is transformed via 2D-FFT. The log-magnitude spectrum is centered and integrated across concentric annuli, producing a normalized 128-bin radial vector $f_{\text{norm\_radial}}$ scored by an MLP.
- **Stage 4 (Metric Subspace Alignment):** Contextual text and visual vectors are projected into a 512-dimensional metric space with Layer Normalization and unit L2-norm scaling, computing normalized cosine consistency $C_{\text{sim}} \in [0, 1]$.
- **Stage 5 (Cross-Attention Fusion):** 8-head bidirectional cross-attention generates attended vectors $T_{\text{attended}}, V_{\text{attended}} \in \mathbb{R}^{512}$. Concatenating these with the frequency profile (128-d) and consistency score (1-d) yields an 1153-dimensional fused representation.
- **Stage 6 (Calibrated Evidential Decision Mapping):** A 3-layer GELU classification head computes raw class logits. An evidential reasoning matrix maps unimodal suspicion scores and cross-modal consistency into a four-way calibrated distribution.
- **Stage 7 (Explainable AI Synthesis):** Token-level attention weights are extracted from the `[CLS]` token across final-layer heads; the 2D power spectrum is mapped through OpenCV's Inferno colormap; and natural language diagnostics are generated.

### 2.3 Standards & Mathematical Formulations
The mathematical foundations of the system include:

1. **Transformer Scaled Dot-Product Self-Attention:**  
   Given token sequence $X \in \mathbb{R}^{L \times d}$, projections yield Queries $Q = X W_Q$, Keys $K = X W_K$, and Values $V = X W_V$:  
   $$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$  
   The contextual sequence representation is extracted from the `[CLS]` token: $h_{\text{CLS}} = \text{RoBERTa}(X)_{[:, 0, :]} \in \mathbb{R}^{768}$.

2. **Prototype Margin Distance Metric:**  
   Let $p_{\text{auth}}, p_{\text{fake}} \in \mathbb{R}^{768}$ denote empirical class centroids. The cosine margin differential is defined as:  
   $$\Delta_{\text{margin}} = \cos(h_{\text{CLS}}, p_{\text{auth}}) - \cos(h_{\text{CLS}}, p_{\text{fake}})$$  
   The uncalibrated textual suspicion probability is derived via a steepness-scaled sigmoid:  
   $$P_{\text{raw\_fake}} = \frac{1}{1 + e^{\kappa \cdot \Delta_{\text{margin}}}}, \quad \kappa = 500.0$$

![Figure 4: Mathematical Formulation 2 - Prototype Margin Distance Metric](/C:/Users/akkir/.gemini/antigravity/brain/07577871-420f-445c-8e26-302e7460cc4d/images/math2_prototype_margin.png)
*Figure 4: Mathematical Formulation 2 - Prototype Margin Distance Metric*

3. **2D Discrete Fourier Transform & Azimuthal Integration:**  
   For grayscale luminance $g(x, y)$ of size $H \times W$, the 2D spatial frequency spectrum is:  
   $$F(u, v) = \sum_{x=0}^{H-1} \sum_{y=0}^{W-1} g(x, y) \cdot e^{-j 2\pi \left(\frac{ux}{H} + \frac{vy}{W}\right)}$$  
   Logarithmic power magnitude is computed with quadrant centering:  
   $$S(u, v) = 20 \cdot \log_{10}(|\text{fftshift}(F(u, v))| + 10^{-8})$$  
   The azimuthal radial profile averages power over concentric annuli at radius $k$ from center $(c_x, c_y)$:  
   $$R(k) = \frac{1}{|\Omega_k|} \sum_{(x, y) \in \Omega_k} S(x, y), \quad \Omega_k = \left\{(x, y) \;\middle|\; \left\lfloor \sqrt{(x - c_x)^2 + (y - c_y)^2} \right\rfloor = k\right\}$$

![Figure 5: Mathematical Formulation 3 - 2D Discrete Fourier Transform & Azimuthal Integration](/C:/Users/akkir/.gemini/antigravity/brain/07577871-420f-445c-8e26-302e7460cc4d/images/math3_2d_fft.png)
*Figure 5: Mathematical Formulation 3 - 2D Discrete Fourier Transform & Azimuthal Integration*

4. **Cross-Modal Metric Projection & Cosine Alignment:**  
   $$u = \frac{\text{LayerNorm}(W_t f_{\text{text}} + b_t)}{\|\text{LayerNorm}(W_t f_{\text{text}} + b_t)\|_2} \in \mathbb{R}^{512}, \quad v = \frac{\text{LayerNorm}(W_v f_{\text{vision}} + b_v)}{\|\text{LayerNorm}(W_v f_{\text{vision}} + b_v)\|_2} \in \mathbb{R}^{512}$$  
   $$C_{\text{sim}} = \text{clamp}\left(\frac{u \cdot v + 1.0}{2.0}, 0.0, 1.0\right)$$

![Figure 6: Mathematical Formulation 4 - Cross-Modal Metric Projection & Cosine Alignment](/C:/Users/akkir/.gemini/antigravity/brain/07577871-420f-445c-8e26-302e7460cc4d/images/math4_metric_projection.png)
*Figure 6: Mathematical Formulation 4 - Cross-Modal Metric Projection & Cosine Alignment*

5. **Bidirectional Multi-Head Cross-Attention:**  
   Text queries attend to visual representations via $Q_t = f_{\text{text\_proj}} W_Q^{(t)}$, $K_v = f_{\text{vision\_proj}} W_K^{(v)}$, $V_v = f_{\text{vision\_proj}} W_V^{(v)}$:  
   $$\text{Attn}_{T \to V} = \text{MultiHead}(Q_t, K_v, V_v)$$  
   $$T_1 = \text{LayerNorm}(f_{\text{text\_proj}} + \text{Attn}_{T \to V}), \quad T_{\text{attended}} = \text{LayerNorm}(T_1 + \text{FFN}(T_1)) \in \mathbb{R}^{512}$$

![Figure 7: Mathematical Formulation 5 - Bidirectional Multi-Head Cross-Attention](/C:/Users/akkir/.gemini/antigravity/brain/07577871-420f-445c-8e26-302e7460cc4d/images/math5_cross_attention.png)
*Figure 7: Mathematical Formulation 5 - Bidirectional Multi-Head Cross-Attention*

6. **Calibrated Evidential Masses for 4-Way Taxonomy:**  
   Let $p_t = P_{\text{text\_fake}}$, $p_v = \max(P_{\text{deepfake}}, S_{\text{forensic}})$, and $c = C_{\text{sim}}$:  
   $$E_{\text{Authentic}} = (1 - p_t) \cdot (1 - p_v) \cdot (0.6 + 0.4 \cdot c)$$  
   $$\text{Penalty}_{\text{mismatch}} = \max(0.0, 0.42 - c) \cdot 1.5$$  
   $$E_{\text{Misleading}} = \max\left(p_t \cdot (1 - p_v), \; \text{Penalty}_{\text{mismatch}}\right)$$  
   $$E_{\text{Manipulated}} = p_v \cdot (1 - p_t)$$  
   $$E_{\text{Multimodal\_Fake}} = p_v \cdot p_t$$  
   The final calibrated probability distribution is normalized: $P_k = \frac{E_k}{\sum_{j=1}^4 E_j}$.

### 6.1 RoBERTa Contextual Text Branch (`text_branch/model.py`)

```python
import os
import torch
import torch.nn as nn
from transformers import RobertaModel, RobertaTokenizer
from typing import Dict, List, Optional

class PretrainedTextBranch(nn.Module):
    """RoBERTa-based text branch with prototype margin discrimination."""
    def __init__(self, model_name="roberta-base", feature_dim=768, device=None):
        super().__init__()
        self.device = torch.device(device or ("cuda" if torch.cuda.is_available() else "cpu"))
        self.tokenizer = RobertaTokenizer.from_pretrained(model_name)
        self.roberta = RobertaModel.from_pretrained(model_name, attn_implementation="eager")
        self.feature_dim = feature_dim
        self.to(self.device)
        self.eval()

    def analyze(self, text: str) -> Dict:
        tokens = self.tokenizer(text, return_tensors="pt", max_length=256, truncation=True, padding=True)
        tokens = {k: v.to(self.device) for k, v in tokens.items()}
        with torch.no_grad():
            outputs = self.roberta(**tokens, output_attentions=True)
            features = outputs.last_hidden_state[:, 0, :]  # [CLS] embedding
            cos_sim_auth = torch.cosine_similarity(features, self.proto_auth)
            cos_sim_fake = torch.cosine_similarity(features, self.proto_fake)
            delta = cos_sim_auth - cos_sim_fake
            raw_fake = 1.0 / (1.0 + torch.exp(500.0 * delta))
            cal_fake = self.calibrate_cues(text, raw_fake.item())
        return {"features": features.cpu().numpy()[0], "fake_prob": cal_fake}
```

### 6.2 Spatial Vision Branch (`vision_branch/model.py`)
```python
import os
import torch
import torch.nn as nn
from torchvision import models, transforms
from PIL import Image

class VisionBranch(nn.Module):
    """EfficientNet-B0 fine-tuned on FaceForensics++ (c23)."""
    def __init__(self, weights_path=None, feature_dim=768, device=None):
        super().__init__()
        self.device = torch.device(device or ("cuda" if torch.cuda.is_available() else "cpu"))
        self.backbone = models.efficientnet_b0(num_classes=2)
        if weights_path and os.path.exists(weights_path):
            self.backbone.load_state_dict(torch.load(weights_path, map_location=self.device))
        self.projector = nn.Linear(1280, feature_dim)
        self.transform = transforms.Compose([
            transforms.Resize((224, 224)),
            transforms.ToTensor(),
            transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
        ])
        self.to(self.device)
        self.eval()

    def analyze(self, image: Image.Image) -> dict:
        t_img = self.transform(image).unsqueeze(0).to(self.device)
        with torch.no_grad():
            feats = self.backbone.features(t_img)
            pooled = self.backbone.avgpool(feats).flatten(1)
            proj = self.projector(pooled)
            logits = self.backbone.classifier(pooled)
            prob = torch.softmax(logits, dim=1)[0, 1].item()
        return {"features": proj.cpu().numpy()[0], "deepfake_prob": prob}
```

### 6.3 Forensic 2D-FFT Branch (`forensic_branch/fft_detector.py`)
```python
import numpy as np
import cv2
from PIL import Image

class ForensicBranch:
    """2D-FFT azimuthal power spectrum radial profile extractor."""
    def extract_fft_spectrum(self, image: Image.Image):
        gray = np.array(image.convert("L"), dtype=np.float32)
        h, w = gray.shape
        f = np.fft.fft2(gray)
        fshift = np.fft.fftshift(f)
        magnitude = 20 * np.log(np.abs(fshift) + 1e-8)
        cy, cx = h // 2, w // 2
        y, x = np.ogrid[:h, :w]
        r = np.sqrt((x - cx)**2 + (y - cy)**2).astype(np.int32)
        max_r = min(cx, cy)
        radial = np.zeros(max_r, dtype=np.float32)
        for i in range(max_r):
            mask = (r == i)
            if np.any(mask):
                radial[i] = np.mean(magnitude[mask])
        xp = np.linspace(0, 1, max_r)
        x_new = np.linspace(0, 1, 128)
        profile_128 = np.interp(x_new, xp, radial)
        norm_prof = (profile_128 - profile_128.min()) / (profile_128.max() - profile_128.min() + 1e-8)
        high_freq_ratio = float(np.mean(norm_prof[96:]))
        return norm_prof, high_freq_ratio
```

### 6.4 Bidirectional Multi-Head Cross-Attention (`fusion/cross_attention.py`)
```python
import torch
import torch.nn as nn

class MultiHeadCrossAttentionBlock(nn.Module):
    """Bidirectional Cross-Attention Block (8 Heads, 512-dim)."""
    def __init__(self, embed_dim=512, num_heads=8, dropout=0.1):
        super().__init__()
        self.t2v_attn = nn.MultiheadAttention(embed_dim, num_heads, dropout=dropout, batch_first=True)
        self.v2t_attn = nn.MultiheadAttention(embed_dim, num_heads, dropout=dropout, batch_first=True)
        self.t_norm1 = nn.LayerNorm(embed_dim)
        self.v_norm1 = nn.LayerNorm(embed_dim)

    def forward(self, text_feat, vision_feat):
        t_attn, t2v_w = self.t2v_attn(query=text_feat, key=vision_feat, value=vision_feat)
        t_out = self.t_norm1(text_feat + t_attn)
        v_attn, v2t_w = self.v2t_attn(query=vision_feat, key=text_feat, value=text_feat)
        v_out = self.v_norm1(vision_feat + v_attn)
        return t_out, v_out, t2v_w, v2t_w
```

### 6.5 Video Analysis Subsystem (`video_branch/video_analyzer.py`)
```python
import cv2
import numpy as np

class VideoAnalyzer:
    """Multi-frame temporal video analyzer with facial tracking and jitter analysis."""
    def __init__(self, detector=None, num_frames=16, risk_threshold=0.55):
        self.detector = detector
        self.num_frames = num_frames
        self.risk_threshold = risk_threshold

    def analyze(self, video_path: str):
        cap = cv2.VideoCapture(video_path)
        total_frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
        indices = np.linspace(0, total_frames - 1, self.num_frames, dtype=int)
        frame_risks = []
        for idx in indices:
            cap.set(cv2.CAP_PROP_POS_FRAMES, idx)
            ret, frame = cap.read()
            if not ret: continue
            risk = self.detector.predict_frame(frame)
            frame_risks.append(risk)
        cap.release()
        top3_risk = float(np.mean(sorted(frame_risks, reverse=True)[:3]))
        temporal_jitter = float(np.std(frame_risks))
        return {
            "video_risk": top3_risk,
            "temporal_jitter": temporal_jitter,
            "is_flagged": top3_risk >= self.risk_threshold
        }
```
